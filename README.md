# 🔑 HashCracker & Generator Core Framework v3.5
> **Developer:** Imran (রানা ভাই / RANA VHAI)  
> **Platform:** Termux / Pydroid 3 (Android Environment)  
> **Architecture:** Modular (Requires external `wordlist.txt`)

একটি শক্তিশালী এবং গতিময় ক্রিপ্টোগ্রাফি ফ্রেমওয়ার্ক, যা বিভিন্ন ধরণের সিকিউর হ্যাশ (Hash) তৈরি করতে এবং আলাদা পাসওয়ার্ড ডাটাবেজ (`wordlist.txt`) ফাইলের সাহায্যে সেগুলোকে ক্র্যাক বা কনভার্ট করতে ব্যবহার করা হয়।

---

## 🚀 বৈশিষ্ট্যসমূহ (Features)
* **মাল্টি-অ্যালগরিদম সাপোর্ট:** MD5, SHA-1, SHA-256 এবং SHA-512 অ্যালগরিদম সাপোর্ট করে।
* **আলাদা ডাটাবেজ আর্কিটেকচার:** মূল পাইথন কোড এবং পাসওয়ার্ড লিস্ট সম্পূর্ণ আলাদা ফাইলে থাকে।
* **ফাইল এক্সপোর্ট সিস্টেম:** জেনারেট করা হ্যাশ সরাসরি `hash_output.txt` ফাইলে সেভ করে রাখা যায়।
* **টার্মিনাল অপটিমাইজড:** কালারফুল ব্যানার এবং ইউজার-ফ্রেন্ডলি ইন্টারফেস।
